# CMC-DL-2025
Deep Learning coursework completed as part of the Deep Learning course at the Faculty of Computational Mathematics and Cybernetics, Lomonosov Moscow State University, 4th year in 2025.

## Topics covered

- Matrix differentiation, analytical gradients and gradient descent from scratch
- Loss functions and regularization: MSE, MAE, L1 and L2
- Linear regression optimization and comparison with scikit-learn
- MNIST classification with PyTorch
- Fully connected neural networks: custom Linear, activation and loss layers
- Training loops, accuracy evaluation and experiments with depth, initialization and activations
- Semantic segmentation with a PSPNet-like architecture
- Custom Dataset/DataLoader, preprocessing and augmentations
- ResNet encoder, pyramid pooling, decoder and segmentation head
- Segmentation metrics and losses: IoU, recall, focal loss and cross-entropy
- Training, validation, testing and logging
